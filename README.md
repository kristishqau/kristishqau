### Tweet Sentiment Analysis

[View repository](https://github.com/kristishqau/SentimentAnalysis_NLP)

A production-minded, four-class sentiment-analysis system designed around trustworthy evaluation rather than inflated random-split results.

- Evaluates 71,117 records across 32 target entities.
- Prevents tweet-ID, exact-text and normalized-text leakage between evaluation folds.
- Achieves 0.6355 macro-F1 with Twitter-RoBERTa across five canonical grouped folds.
- Improves macro-F1 by 11.76% over the strongest classical baseline.
- Includes nested evaluation, class-level error analysis, model and data cards, CLIs and a browser demo.
- Provides 30 tests, 90%+ coverage, Python 3.11-3.14 CI, dependency auditing and a hardened container workflow.

**Engineering themes:** machine learning evaluation, reproducibility, data leakage, NLP, testing, CI/CD and deployment tradeoffs.
